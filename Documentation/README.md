# Adobe Experience Platform Flags Mobile Extension for iOS

The Flags mobile extension (`AEPFlags`) lets an iOS app evaluate feature flags that you manage in Experience Flags. In Data Collection, the extension is listed as **Adobe Flags**.

## Documentation

- [Getting started](sources/getting-started.md): requirements, Data Collection setup, installation, and SDK initialization
- [API usage](sources/api-usage.md): public APIs, evaluation context, custom identity, and error handling
- [Exposure analytics](sources/exposure-analytics.md): the feature exposure data that the extension sends to Adobe Experience Platform
- [Sample app setup](sources/testapp-setup.md): how to run the Swift and Objective-C sample apps
